# CodyBot 3.0

Prima versione operativa del pannello flottante sopra CodyCross.

## Cosa fa
- AccessibilityService con pannello SCAN/AUTO/STOP.
- Permesso di cattura schermo tramite MediaProjection.
- OCR on-device con ML Kit.
- Selezione della zona dell'indizio nella schermata CodyCross.
- Risoluzione di due indizi di riferimento e tentativo di ricerca web per gli altri.
- Preparazione per la fase successiva: riconoscimento griglia, lunghezza/lettere note e compilazione con dispatchGesture.

## Build
GitHub Actions genera `CodyBot-3.0-debug-apk`.
